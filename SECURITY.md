# Security Policy

## Reporting a Vulnerability

Do **not** put secrets or exploit details in a public issue.

1. Preferred: open a **private** [GitHub Security Advisory](https://github.com/UnoDomination/llm-guard/security/advisories/new) on this repo (Settings → Security → Advisories, if enabled).
2. Or open a [GitHub Issue](https://github.com/UnoDomination/llm-guard/issues/new) titled `SECURITY: …` with a short description and steps to reproduce (no full weaponized PoC in public if avoidable).

Watching / starring the repo is optional; opening an issue notifies the maintainer.

### What to include

- Description of the vulnerability
- Steps to reproduce
- Affected scanners or versions if known

### Scanner gaps and feature ideas

Open a normal [GitHub Issue](https://github.com/UnoDomination/llm-guard/issues/new) for scanner false negatives, new attack patterns, or feature ideas.

## Contact

No public email. Please use GitHub Issues (or a private Security Advisory). The maintainer is alerted through GitHub notifications.
